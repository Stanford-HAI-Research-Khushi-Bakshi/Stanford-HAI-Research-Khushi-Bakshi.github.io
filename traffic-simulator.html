Assessment / demo utility

Anonymous traffic simulator

This utility is not part of the customer-facing website. It sends realistic, anonymous demo journeys to the configured PostHog project so the assessment dashboard can show tutor interest, subject demand, and booking drop-off.

No personal data

Simulations never include parent names, student names, emails, phone numbers, or booking details. They do not read or change customer-site bookings.

Ready to generate anonymous demo traffic.

Each batch includes

  • Several tutor profile views across the existing sample tutors
  • A mix of Math, English, Science, Test Prep, and Study Skills filters
  • Some booking starts and fewer booking completions to show funnel drop-off
  • Anonymous page views and grade-filter selections
